🧪 ScreenCV API Testing

Visual interface to test all 4 endpoints - No terminal needed!

1️⃣ Submit Resume

POST /api/candidate/submit
Upload PDF, DOCX, DOC, or TXT files

2️⃣ Create Payment

POST /api/candidate/create-payment
Get this from the response of "Submit Resume" (Step 1)
Price is fixed at ₹99 (Mock payment for testing)

3️⃣ Payment Webhook

POST /api/candidate/payment-webhook
Get this from the response of "Create Payment" (Step 2)
Optional - will be auto-generated if empty
⚠️ This endpoint triggers the full workflow: Resume analysis, PDF generation, and email sending. It may take 10-30 seconds to complete.

4️⃣ Extract Job URL

POST /api/candidate/extract-job-url
LinkedIn, Indeed, or any job posting URL. If extraction fails, manual paste is the fallback.

🚀 How to Test

1. Start Local Server: Run npm run dev in your terminal

2. Fill Step 1: Enter resume and job details, click "Send Request"

3. Copy submissionId: Paste it into Step 2's "Submission ID" field

4. Create Payment: Click "Create Order", copy the orderId from response

5. Paste orderId: Into Step 3's "Order ID" field

6. Confirm Payment: Click "Confirm Payment" - this runs the full analysis!

7. Check Response: See score, flags, interview questions in the response

💡 Tip: Keep .env.local filled with your Supabase and Anthropic credentials!
